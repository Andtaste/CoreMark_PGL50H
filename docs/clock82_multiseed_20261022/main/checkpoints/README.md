# 82 MHz 固定映射检查点

采纳的 CPU 源码、PLL、镜像和约束必须与 `clock82_checkpoint.json` 的 SHA 一致。
检查点由本轮真实 82 MHz 工程综合映射产生，布局 seed 22、路由 seed 4 已独立复现。

`../new_core.tcl` 默认重新编译、综合、映射，再检查全部输入 SHA 和完整 25 模块结构网表。
检查通过后装入这里的固定映射，再由 PDS 重新布局、布线和运行多角 STA。
寄存器文件的 128 个等价 RAM 读副本可能在重新综合时交换实例名；相同 seed 在不同映射上不保证相同结果。
结构检查保留每一条语句、重复次数、端口连接、位号和参数，只允许这些 RAM 副本名作一一对应置换。

修改 RTL、IP、镜像或 FDC 后，构建入口会拒绝复用检查点。
此时请使用 `../rebuild_from_rtl.tcl` 生成新映射，并重新验证布局种子和时序。
PDS GUI 直接重新综合会生成新映射；完整复现本轮结果请运行 `../new_core.tcl`。
当前 PDS 的源文件、时钟和最终 STA 均指向实际 82 MHz 方案。

原 80 MHz 工程完整备份在 `../../pds80_before_clock82_20261022`。
