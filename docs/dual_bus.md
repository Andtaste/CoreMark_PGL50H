## 改了什么，为什么等价

原依赖是：FIFO 读指针 → 异步队首地址 → 通用 `dr`（含 UART 忙判断）→ `da_fire` →
同一 RAM 行的读写碰撞判断 → `ir/ia_fire` → RAM A 口使能。
这是上轮候选的第二差路径，WNS +1.343 ns；第一差为 RAM 输出 → IF 分类寄存器，+1.340 ns，差 3 ps。

拆授权版单独计算：

```verilog
data_slot = rst_n && (!dpending || dor);
ram_write_offer = dv && data_slot && dwrite;
collision = ram_write_offer && same_bank && same_row;
```

原 `dr` 和 MMIO/UART 接收行为保留。只有当数据地址属于 RAM 时，碰撞才可能成立，
这时 UART 地址判断必为假，所以 `dr` 中的 UART 忙条件对于碰撞结果是冗余项。

局部使能版继续把碰撞拆成 code/data 两个银行，各银行 A 口直接使用自己的碰撞保护与取指空间条件；
B 口也从 RAM 专用授权产生使能，减少经过公共 `collision→ir→ia_fire` 的绕行。
全局 `ir` 仍是精确的原有请求接收条件，返回 metadata 也按同样边沿更新。
无效地址、未对齐取指、字节写、同一 8 字节行的不同 32 位半字、MMIO 等行为都保持不变。

**它是组合路径压短，没有靠新寄存器将这条 MEM→IF 依赖完全切断。**
EX/MEM FIFO、操作数队列和容量信用边界均未变；没有添加 EX 直驱 RAM、RAM 返回直通 EX 或
MEM ready → EX → ID → IF 的组合回传。除 `nc_local_bus.v` 外，各核心/前端候选源文件与上轮逐字节相同。

## 对同类路径作定向 STA，而非只看前 30 名

额外从三版已经完成布局布线的 `top_pnr.adf` 读取结果，不重新运行布局布线。
统一筛选两个 FIFO `rd*/CLK` 到全部 48 个 RAM A 口 CEA 的路径，每版取最差者。
因此局部使能路径退出全局最差 30 条后，仍有可核对的测量结果。

| 同类路径最差者 | 逻辑级 | 逻辑 / ns | 布线 / ns | setup WNS / ns | 数据网最大扇出 |
|---|---:|---:|---:|---:|---:|
| 上轮候选 | 9 | 2.738 | 8.987 | +1.343 | 212 |
| 拆授权 | 8 | 3.043 | 8.646 | +1.379 | 212 |
| 局部使能 | **4** | **1.654** | **6.610** | **+4.925** | 213 |

局部使能版此类路径 WNS 改善 **3.582 ns**，原 `uart_addr` 已不在两候选的定向最差路径中。
拆授权版虽然少一级，PDS 映射的单元延迟反而更大，所以逻辑延迟没有随级数减少。
FIFO 指针扇出仍为 212/213，未通过本轮得到解决；局部 RAM 使能也仍有较长布线。
表中筛选条件相同，但物理最差的指针位和 RAM 端点可随布局改变，不是强行固定同一条网线。

两候选的整核限制仍为 **RAM A 输出 → IF 分类标志寄存器**：

| 实现 | 最差路径端点 | 逻辑级 | 逻辑 / ns | 布线 / ns |
|---|---|---:|---:|---:|
| 拆授权 | fetch/head_flags[4] | 7 | 5.172 | 6.517 |
| 局部使能 | fetch/flags_2[4]（另有 flags_3[4] 同余量） | 7 | 5.123 | 7.690 |

这条 IF 路径在本轮前已几乎并列最差；总线重写也改变了整体映射和布局，不能假设其他路径延迟不变。
现有一次布局结果说明局部瓶颈被改善、整核仍受 IF 路径限制，不能据此把整体下降全归因于某一个物理因素，
也不能把路径压短宣称为整核提频成功。因此不把这两版合并到推荐候选。

## 验证与证据

两候选分别完成：

- 63 项原有整核回归，含 47 项 RV32UI/UM 继承指令测试；5 项双发附加检查，含故障撤销、RAW/WAW/WAR 和连续双退休。
- 固定 10 次性能镜像、固定 1 次验证镜像，全部统计与上轮相同。
- 原总线与新总线 100,000 拍双实例对照、200,000 次边沿前后检查：请求接收、返回控制/数据、UART、GPIO、timer、tohost 和四个 RAM 端口使能一致。
  覆盖 code/data 同行碰撞 4,379/4,436 次、UART 忙 9,955 次、UART 忙时仍能取指 3,103 次、连续接收/返回 19,647 次。

  该证明仅覆盖组合控制锥，不宣称整核顺序逻辑形式认证。
- Verilator lint 无锁存器、组合环、多驱动、未驱动、隐式网线和端口缺失。其余包字段/trace 未使用位、空端口与宽度警告保持原数量。

生成 IP 配置、初始化参数和模型均与上轮逐字节相同，继续沿用上轮真实紫光原语的初始化/字节写读回验证；
本轮新增的 RAM 端口控制已由 SAT 和逐拍仿真检查，没有重新宣称执行了一遍 IP 初始化测试。
